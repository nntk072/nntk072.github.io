## 🌐 Deploying to GitHub Pages (Free & Instant)
1. Initialize git in this directory:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio website"
   ```
2. Create a new repository on your GitHub (e.g. `longnguyen.github.io` or `portfolio`).
3. Push to GitHub and enable **Settings > Pages > Deploy from Branch (main / root)**.
4. Your website will be live in 1 minute!
